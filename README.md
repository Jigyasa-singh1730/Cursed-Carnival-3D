# Cursed Carnival: The Midnight Fair 3D

**Cursed Carnival** is a colourful 3D horror survival game built using HTML, CSS, JavaScript, and Three.js. Explore a mysterious neon-lit carnival, collect hidden keys, avoid the chasing clown, and find the exit before your lives run out.

## About the Project

A mysterious carnival looks beautiful from the outside, but something strange is happening inside. A terrifying clown is chasing you, and your only chance to escape is to find three hidden keys and reach the exit gate.

Explore the 3D environment, collect keys, avoid the enemy, and survive the midnight fair!

## Features

- 3D environment powered by Three.js.
- Neon-themed haunted carnival atmosphere.
- Animated Ferris wheel.
- Colourful circus tent and decorative environment.
- 3D player and clown enemy.
- Enemy chase mechanics.
- Collectible keys.
- Exit gate and win condition.
- Lives and game-over system.
- Keyboard and mobile touch controls.
- Third-person camera.

## Technologies Used

## How to Run Locally

1. Clone the repository:

```bash
git clone YOUR-GITHUB-REPOSITORY-LINK
```

2. Open the project folder in Visual Studio Code.

3. Make sure you have the Live Server extension installed.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

6. Enjoy the game!

An active internet connection is required to load the Three.js library from its CDN.

## Game Controls

| Key | Action |
|---|---|
| W / Up Arrow | Move Forward |
| S / Down Arrow | Move Backward |
| A / Left Arrow | Move Left |
| D / Right Arrow | Move Right |
| Mobile Arrow Buttons | Move Player |
